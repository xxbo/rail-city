# P3-0：行为基线、生产边界与Rust会话基础

审计基线：bffdd8fbd22e2553a881533b540f878f6ea8fabc（MAP65）。计划提交：9e06a5991fca2d09155b7aa989370e1dc1d9165b。目标和后续顺序见[rust-ui-only-plan.md](rust-ui-only-plan.md)。

## 本阶段交付

1. AST逐函数清单：77个生产JS模块、1,804个函数（含方法、箭头、回调和IIFE），72个页面脚本与5个Worker入口。清单记录行号、函数体SHA、全局导出/公开名称候选、页面/Worker上下文、生产/测试引用候选、目标职责与阶段。
2. 迁移政策：按模块及明确命名函数覆盖规则为所有函数分配去向；闭包继承最近已指定的命名作用域。模块级默认值/静态初始化由模块所有者负责，文件SHA也进入门禁。
3. Rust会话原型：同一接口可在无DOM的Rust单测和WASM中打开冷世界、查询、预览、提交及关闭；复用现有资产/编辑实现。
4. 原型协议与平台绑定选择，明确修订、幂等、失败原子性、快照隔离和未来平台边界。
5. 固定MAP65测试夹具及CI门禁；原型和审计工具均位于开发目录，当前生产WASM保持原字节。

## 基线与原型验证

冻结来源必须是干净的精确MAP65工作树，由freeze_rail_p3.cjs检查HEAD与跟踪文件状态。夹具保存东京/大湾区冷世界、原生资产规则的完整有序输出、四组现代/加权运行场景的完整状态及运行快照，以及Rust原生测试直接读取的wire。比较完整字段及JSON顺序，不删除不一致字段。

- Rust默认构建：原有42项单测与生产WASM字节检查。
- 启用session-contract：44项Rust单测，含无DOM打开会话/提交/重复命令/查询以及坏协议输入。
- 新会话专项：325项协议检查，加两地图完整有序世界、资产结果与四组MAP65运行轨迹对照。
- 新边界专项：77模块、1,804函数、页面与5Worker，以及注入式反例。
- 原有全量回归与真实Chromium探针由独立游戏CI执行。浏览器结果作为独立验证artifact保留。

当前会话原型只验证冷资产事务；活动乘客/城市/RNG等状态仍由后续阶段转移。[完整接口合同](p3-session-contract.md)明确已实现和预留能力。

## 性能与发布影响

本阶段未接入新的生产执行路径。77个生产JS源文件保持MAP65字节，生产rail-core-v25.wasm仍为1,634,578字节，SHA-256为e9f8b39f6a1a751ff3a52f20cb05b54514a0a256d6bb6ef9e872e0ace415bfa5。审计、解析器、golden和原型WASM均在scripts目录，不进入Pages产物。

因此相对上一版及未Rust的新增运行时收益均未产生；本阶段价值是固定合同、明确迁移缺口与形成回归门禁。沿用MAP65性能记录，不把其结果冒充P3-0新跑分，也不将原型测试的耗时作为游戏吞吐。

原型WASM的构建、单测及逐字节核对单独进入CI。默认生产构建保持原源码行位置，避免仅新增feature模块就改变已冻结的WASM内嵌位置数据。PR只验证，main验证通过后发布的原有约束保留。
