# 独立游戏仓边界复核

当前分支仅包含游戏源代码/地图/资产、Rust内核、游戏测试/冻结基线/性能脚本，以及独立游戏CI。

资讯站的页面与信息流、财经/新闻采集器、dashboard数据、资讯测试、资讯定时刷新和组合发布流水线均已移出。`scripts/test_rail_repository.cjs` 持续检查边界。

以下引用有明确用途，保留：

- “返回观潮”是外部导航链接，不加载资讯模块。
- `guanchao-rail-*` localStorage键和 `guanchao-rail-checkpoints` IndexedDB名称属于游戏存档兼容协议；改名会影响既有进度读取。
- README和历史验收报告保留迁移来源及原提交SHA。
- Git历史保留分仓前共享仓的原提交；当前分支的文件边界与历史提交的内容分别评价。

P2-3仅在本仓推进，资讯仓不参与构建、测试或发布。
