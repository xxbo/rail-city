## 本批修改的验证结果

1. **客流临时缓冲。** arrival 包预估容量和原地补协议头已编译；新增 Rust 单测验证完整 wire 顺序，以及预留容量时复用同一分配。旧东京全线网仍在预热阶段发生 WASM trap，内存问题继续计入未解决项。
2. **完整快照摘要。** 完整 checkpoint 改用专门 nativeView 投影，减少第二棵列车/定义视图的重复构造。新增的摘要 wire 与原 compact 视图逐字段/顺序一致断言通过；Node 原生快照、Worker 交接和恢复续跑回归也通过。
3. **预算与空推进。** 新 Rust 单测验证预算拒绝不改变 pending，空闲返回 steps=0，完成返回真实步数。原生 Node 回归验证完整推进拒绝负数、NaN、Infinity 和过大请求，拒绝后完整 arena 不变；零推进返回完整批次形状。阻塞账户保留 blocked 原因，零推进不补算城市/运营审查；完整推进累积多个批次事件。
4. **原生重绑定。** rebind 从原生 snapshot 读取状态，先构建新 arena 再释放旧 arena。修改 JS 显示时间和计数后重绑定，完整原生 checkpoint 保持不变的回归通过。Worker 沿用异步原生编辑/恢复入口。
5. **退休与删线用例。** MAP58 retirement、MAP59 reroutes 已使用结构化原生命令，MAP58 首个删站场景的预览只读、一次收费断言已执行通过；旧同步 reconcile 的当前会话调用已移除。完整世界对照继续失败，且已显示实际客流和财务数值差异，不能仅按元数据/浮点尾差处理。
6. **原生重路由观测。** storage 查询新增本 arena 的 nativeReroutes，用例改读实际会话计数，并保留真实 Worker、实际转乘和零主线程 reroute 的验证目标。两组用例目前在更早的完整世界对照处失败，后续断言尚不能据此判为通过。

正式 WASM 为 2,980,375 字节，SHA-256 为 `d1a38466b9dcd83bb2f57f233a7cf224d4b505f27cc58d68c6bbeb2d139b09f6`；本地和 CI 正式构建一致。源码边界验证覆盖 80 个模块、1,564 个函数、69 个页面脚本和 3 个引用 Worker。原始冻结 JSON/wire 及完整世界、完整快照业务断言保留。
